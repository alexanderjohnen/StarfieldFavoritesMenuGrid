Title:
Favorites Menu Grid - SFSE

Summary:
Shows every favorites row at once as a grid you can click and edit. Move
favorites between slots and rows, delete them, and see which key fires each
column. A fork of Favorites Banks.

Version:
1.0.1

Category:
User Interface

Tags:
User Interface, Utilities for Players, Quality of Life

File display name:
Favorites Menu Grid 1.0.1

Source display name:
Favorites Menu Grid 1.0.1 - Source Code

Main file description:
Loading a save this mod has never seen - one made before you installed it -
now starts from that save's own favorites on your default row instead of
carrying over the rows of the save you just left. Cells whose icon the game
has not handed over yet show the item's name instead of appearing empty.
Requires Starfield 1.16.244.0, SFSE and the matching Address Library.
Replaces Favorites Banks; do not run both.
